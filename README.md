# Real Estate

A property-focused website for real estate agents, agencies, and property managers. Showcases listings, builds agent credibility, and captures seller leads through free appraisal forms. This blueprint is built around the two things that win listings: proof you sell well and a low-friction way to get in touch.

## What You Get

- **Hero + Search** -- Agent brand, featured property image, and a property search or browse prompt
- **Featured Listings** -- 3-6 properties displayed with bed, bath, and car icons, plus price guides
- **Agent Profile** -- Years of experience, sales stats, professional headshot, and licence number
- **Areas of Expertise** -- Specialist suburbs with descriptions that build local authority
- **Testimonials** -- Vendor and buyer reviews that prove you deliver results
- **Free Appraisal Form** -- Lead generation form capturing address, property type, and contact details

## Two Ways to Build

### IDE Path (Claude Code, Cursor, Codex)
1. Clone this blueprint into your project
2. Open `CLAUDE.md` -- it's the router file for your AI coding tool
3. Read the PRD in `docs/01-planning/product-requirements/`
4. Open the build prompt in `docs/02-working/prompts/active/`
5. Point your AI tool at the prompt and build

### Host Direct Path (Claude Desktop)
1. Open Claude Desktop with WaymakerOS connected
2. Say: "Build a website for me -- I am a real estate agent in the Eastern Suburbs of Sydney, specialising in luxury apartments."
3. Answer the questions about your business
4. The AI builds and deploys your website via Host Direct

**Estimated build time:** ~15 minutes with either path.
